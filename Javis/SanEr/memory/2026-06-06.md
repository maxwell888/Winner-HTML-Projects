## 5. 矩阵的几个硬结论

1. **8/9 都能走商单**——起号成功是基本盘
2. **5/9 是自有品牌金矿**：母婴选品 / 儿童食品 / 反种草选品 / 服装 / 家居
3. **第 8/9 行（夫妻档 + 反种草）是放大器**——给所有其他护城河加成 30-50%
4. **起号最快**：母婴 / 食品 / 反种草（焦虑型内容，自带搜索流量）
5. **M1 启动两件零成本大事**：① 夫妻档人设（杨珂出镜出声音）② 反种草系列
