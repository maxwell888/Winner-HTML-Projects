# 「设计师妈妈的服装实验室」Phase 2 — 夫妻档人设脚本

> **专项**：5 条"夫妻档"口播视频脚本（杨珂真人出镜 + 出声音版）
> **使用对象**：李曼曼 + 杨珂（拍摄时由太太主导发布节奏，先生主导检测与出镜）
> **目标阶段**：Phase 1 破冰期（M1 启动核心 = 夫妻档人设 + 反种草系列）
> **文件版本**：v1.0（首版，曼曼点头后可继续迭代）
> **编制日期**：2026-06-08

---

## 📋 使用说明

**1. 这是脚本，不是定稿。**
5 条脚本是"夫妻档"系列的开篇候选，每条都有 3 个标题候选和明确的镜头切换清单。**最终定稿必须曼曼自己改一遍**——她熟悉自己的语气、我只是提供"专业但有点笨拙的理工男老公"这个角色的初次骨架。

**2. 杨珂出镜 = 真实、本分、不表演。**
这个账号的反差是"理工男老公 + 设计师老婆"，不是"段子手老公 + 老婆在边上捧哏"。所以杨珂的镜头要**真的有点紧张、真的有点卡壳**——剪的时候**不要全剪掉**，留一点"嗯..."和"等下我想想"的反应，比完美的话术更可爱。

**3. 顺序建议。**
5 条脚本不是"任选其一"，是建议的**发布顺序**。先发 Script 1（破冰）→ Script 2（答非所问圈粉）→ Script 3（闲鱼买设备）→ Script 4（实验过程）→ Script 5（深夜复盘）。每条间隔 2-3 天，留出拍摄+剪辑+复盘时间。

**4. 每条都有"为什么"。**
每条脚本最后一段"选题理由"是为了让曼曼/杨珂判断"这条对账号有什么贡献"。比如 Script 1 是打"账号认知"，Script 2 是打"记忆点"——前期 5 条要分别建立不同的认知锚点。

**5. 拍摄时长与产出。**
每条视频最终成片 30-60 秒，但**实际拍摄建议拍 5-10 分钟**。杨珂不习惯镜头会 NG 多次，曼曼在边上"再笑一次"、"再正经一次"的互动本身就是素材。**剪的时候要"狠"——5 分钟剪成 45 秒**。

**6. 设备与场景。**
所有脚本的默认场景是"家里书房/实验室一角"。需要的设备：
- 一台手机（主摄，曼曼手持或三脚架固定）
- 一台手机/相机（副机位，拍杨珂的侧脸/手部特写，曼曼拍摄）
- 七件检测设备按脚本需求
- 一支补光灯（淘宝 30 元那种夹子款即可，**不追求专业**）

**7. 这版脚本的边界。**
我没有拍过你们家书房的实际光线、不知道女儿几时在客厅、杨珂写代码的桌子长什么样——**所以"镜头切换清单"是参考版，不是分镜脚本**。真正开拍前，曼曼需要把每个镜位的实际位置在脑子里过一遍。

# Script 1 — 反差破冰型

> **主题**：QA 工程师老公 + 设计师老婆，介绍"全网唯一有家庭实验室的穿搭博主"

## 标题候选

1. 服装设计师老婆 + 质量工程师老公，在家建了个实验室测衣服（破防了）
2. 我老公是 QA 工程师，他说"这件好不好"只说数据不说好看
3. 全网唯一有家庭实验室的穿搭博主，居然是我俩这种

> 公式拆解：身份+反差（候选 1）+ 痛点+反常识（候选 2）+ 数字"唯一"+ 情绪词"居然"（候选 3）

## 封面方向

夫妻并排坐书桌前，杨珂面前摊着显微镜，曼曼手指着旁边一件 T 恤。表情：**杨珂严肃像在写报告，曼曼在笑**。**反差感直接拉满**。

## 开头 3 秒钩子

> **杨珂正对镜头**（紧张地摸一下鼻子）："我老婆说……让我也出镜讲两句。"

**为什么这样写**：前 3 秒不是"我们是谁"这种无效信息，而是**老公被老婆"赶鸭子上架"的真实反应**——直接点出"夫妻"和"被迫营业"两个标签。

## 完整口播文案

> **杨珂**（正对镜头，语速偏慢，有点卡顿）：
> "呃……大家好。我叫杨珂，是个……质量工程师。就是做检测那种。"
>
> **杨珂**（伸手把显微镜拉到镜头前）：
> "这是我老婆李曼曼。她是……呃……服装设计专业毕业，还当过奢侈品柜姐。"
>
> **杨珂**（低头看一眼设备清单，再抬头）：
> "她现在想做一个……穿搭博主。但是她说市场上那些……只看图就推荐衣服的，她不放心。"
>
> **杨珂**（有点小骄傲的语气）：
> "所以我就……在家里给她整了一套实验室。显微镜、紫外灯、甲醛试剂……都买了。"
>
> **杨珂**（看着镜头外的曼曼，又转回镜头）：
> "我们俩晚上十点开始做实验，做到十一点。然后我……整理数据，她写文案。"
>
> **杨珂**（最后认真脸）：
> "她说想做全网唯一一个有家庭实验室的穿搭博主。我……就觉得，陪她做吧。"

> **曼曼**（从镜头外插话）："你说完了吗？"
> **杨珂**（松一口气）："说完了。"
> **曼曼**："欢迎大家关注我们。我是曼曼，他是杨珂。"

|------|------|---------|

| 00:05-00:10 | 切到俯拍桌面 | 显微镜 + 七件设备摆开（横扫一遍） |
| 00:10-00:15 | 切回中景 | 杨珂说"奢侈品柜姐"时看镜头外（曼曼方向） |
| 00:15-00:25 | 特写手部 | 杨珂手指点过显微镜、UV 灯、试剂盒 |
| 00:25-00:40 | 中景 | 杨珂说"晚上十点"时，可切到空镜（实验室桌前夜灯） |
| 00:40-00:50 | 中景 | 杨珂"陪她做吧"——**这句要慢** |
| 00:50-00:60 | 双人镜头 | 曼曼入镜，从镜头外探进来；杨珂松一口气 |

## 结尾引导语

> **曼曼**（正对镜头）："大家可以关注一下。我们会一条一条测衣服给你们看。评论区告诉我……你们最想测什么。"

## 标签 3-5 个

`#夫妻档` `#穿搭博主` `#服装检测` `#家庭实验室` `#设计师妈妈`

## 选题理由

**这条是 M1 第一条，承担"账号认知建立"的功能**。

- **建立反差记忆点**：理工男 + 设计师老婆 + 家庭实验室 = 3 个标签一次性植入
- **真人出镜露面**：杨珂是 QA 工程师不是博主，第一次出镜的"卡顿感"反而是真实感的来源
- **曼曼从镜头外入镜**：埋下"她是主角"的伏笔，但同时给足杨珂面子
- **引出"晚上 10 点"**：自然带出协作时间，为后续 Script 5 铺垫

> **风险提示**：如果杨珂实在放不开，**让曼曼先讲完，最后 5 秒杨珂露脸说一句"我是杨珂，做检测的那个"**——也能用。但 Script 1 是为后面 4 条"杨珂为主出镜"做铺垫的，能拍成"杨珂主讲"更好。

# Script 2 — 理工男答非所问型

> **主题**：老婆问"好不好看" vs 老公回"克重 180g"

## 标题候选

1. 我问老公这件 T 恤好不好看，他居然回我"克重 180 克"
2. 跟 QA 工程师老公聊穿搭，三句话离不开"克重""经纬密度"
3. 服装设计师老婆 vs 质量工程师老公，衣服好不好看的标准能差多大

> 公式拆解：身份冲突+反常识回答（候选 1）+ 数字专业词+反差（候选 2）+ 痛点共鸣+反问（候选 3）

## 封面方向

曼曼手举一件白 T 恤（侧脸，正对镜头外），杨珂在另一侧对着手机屏幕（装作看数据）。**两人在画面里"鸡同鸭讲"**——曼曼期待脸 vs 杨珂严肃脸。

## 开头 3 秒钩子

> **曼曼**（边举衣服边问）："老公，这件好不好看？"
> **杨珂**（接过衣服捏了一下，皱眉头）："嗯……面料克重 165 克。"

**为什么这样写**：前 3 秒**直接呈现冲突**——观众还没搞清楚谁是谁，就已经被"这两人说话怎么不在一个频道"吸引住了。

## 完整口播文案

> **曼曼**（举着 T 恤，眼睛亮亮的）："老公老公，你看这件 T 恤。我今天刚买的，¥299，好看吗？"
>
> **杨珂**（接过 T 恤，捏面料，眯眼）："嗯……面料手感偏软，但克重偏低。165 克左右……支数估计 32 支。"
>
> **曼曼**（撒娇脸）："我问你好不好看！"
>
> **杨珂**（依然严肃）："好不好看我不评价。但是……这个克重洗 5 次会变形。领口工艺也一般，螺纹密度……"
>
> **曼曼**（打断他）："行行行。我再问你一件——"
> **曼曼**（又拿出一件，¥89 的淘宝爆款）："这件呢？这件便宜。好看吗？"
>
> **杨珂**（接过来对比，意外地"嗯"了一声）："这件……克重反而高一点。195 克。面料……有点意外。"
>
> **曼曼**（崩溃脸）："所以到底哪件好看？"
>
> **杨珂**（认真想了一下）："我老婆穿哪件都好看。"

> **曼曼**（愣一秒）："……你早这么说不行吗？"
> **杨珂**（很认真的脸）："你说的好不好看……跟我想的好不好看，是两个事。"

## 中间镜头切换清单

| 时间 | 镜头 | 画面内容 |
|------|------|---------|
| 00:00-00:05 | 双人中景 | 曼曼举 T 恤问，杨珂接过去 |
| 00:05-00:12 | 特写手部 | 杨珂捏面料、抖开看 |
| 00:12-00:18 | 中景 | 曼曼撒娇脸 |
| 00:18-00:28 | 中景 | 杨珂说"洗 5 次会变形"（**这里要切一个"认真脸"特写**） |
| 00:28-00:35 | 双人中景 | 曼曼拿出第二件 T 恤对比 |
| 00:35-00:45 | 中景 | 杨珂"嗯"那一声（**这个"嗯"是名场面，要拍正面**） |
| 00:45-00:55 | 中景 | 曼曼崩溃 → 杨珂深情回复 |
| 00:55-01:00 | 双人中景 | 收尾"两个事" |

## 结尾引导语

> **曼曼**（对着镜头，假装吐槽）："你们身边有这种人吗？问东答西那种……评论区告诉我。"
> **杨珂**（小声补一句）："但是我的数据是对的。"

## 标签 3-5 个

`#理工男老公` `#夫妻日常` `#穿搭避坑` `#QA工程师` `#真实夫妻`

## 选题理由

**这条是"记忆点"内容**——不科普不检测，纯粹立人设。

- **制造"金句"**："克重 180 克"、"我老婆穿哪件都好看"、"两个事"——这三句都有成为评论金句的潜力
- **不卷专业知识**：观众不一定懂克重，但**懂"答非所问"的尴尬**——这是大众共鸣
- **杨珂"深情一句"是钩子**：留一个意外的暖点，避免杨珂被贴上"无聊理工男"的标签
- **评论区天然高互动**："你们老公也是这样吗"是经典评论钩子，CES 算法加成

> **风险提示**：如果曼曼担心"显得老公太直男"，可以把杨珂最后那句"我老婆穿哪件都好看"再设计得**更早出现**——比如在第二件 T 恤后立刻说，让"理工直男 + 偶尔暖"的人设更稳。

# Script 3 — 设备采购日记型

> **主题**：先生在闲鱼买显微镜，太太在边上吐槽

## 标题候选

1. 老公在闲鱼蹲了 2 周，花 ¥120 买了个显微镜说"实验室核心设备"
2. 我老公买检测设备的过程，像在选配电脑——CPU、内存、像素都给我列了
3. 闲鱼 ¥120 vs 淘宝 ¥350 的显微镜到底差在哪？我老公拆给我看

> 公式拆解：时间数字+真实价格+反差（候选 1）+ 类比+反常识（候选 2）+ 数字对比+人称（候选 3）

## 封面方向

桌上并排放着两台显微镜（一新一旧），杨珂手里举着工具准备拆机，曼曼在边上双手叉腰"监工"。**用"价格差 230 元"做视觉对比**。

## 开头 3 秒钩子

> **曼曼**（指着桌上的显微镜，夸张脸）："我家这位……为了给我省 230 块显微镜钱，在闲鱼蹲了两周。"

**为什么这样写**：数字"230 块"和"两周"在前 3 秒制造**反差钩子**——观众会立刻想"省 230 块值得两周吗？"。

## 完整口播文案

> **曼曼**（边拆包裹边念叨）："到了到了！这是他从闲鱼蹲的……Andonstar AD106S 显微镜。卖家说九成新，¥120 包邮。"
>
> **杨珂**（已经在桌前摆好工具，认真脸）："我先说一下为什么选 AD106S。它的有效像素 200 万，LED 环形灯 8 颗，带……偏振光滤片——这个是测纤维取向度的关键。"
>
> **曼曼**（直接打断）："停停停。我问你，这跟淘宝全新的 ¥350 那款，差在哪？"
>
> **杨珂**（推了一下眼镜，开始比划）："全新那款带 HDMI 接口，可以直连显示器。我这台只有 USB，连电脑。我主要是拍显微图发小红书，USB 够用。"
>
> **曼曼**："那你怎么保证它没坏？"
>
> **杨珂**（很自信）："我让卖家拍了……光路测试视频、对焦测试、调焦旋钮顺滑度……还问了生产批次，2024 年的，跟全新差半年。**买二手检测设备，最关键是看光路系统有没有进灰，传感器有没有坏点**——这些我都会测。"
>
> **曼曼**（对镜头）："你们看，这就是我家那个……买个显微镜跟选电脑 CPU 一样。"

> **杨珂**（边拆包裹边说）："但是……能省 ¥230。我给你省下来了。"
> **曼曼**（叹气+笑）："行吧，今天晚上就开光。测什么？"
> **杨珂**："你那件 ¥299 的 T 恤……还有那件 ¥89 的。"

## 中间镜头切换清单

| 00:00-00:05 | 俯拍桌面 | 拆包裹，露出显微镜盒 |
| 00:05-00:12 | 中景 | 曼曼边拆边念叨 |
| 00:12-00:22 | 中景 | 杨珂开始讲 AD106S 参数（**这里要切杨珂手部+镜头的特写**） |

## 结尾引导语

> **曼曼**："这是我们的第一期……设备开箱。下期我们就用这台显微镜……测我那两件 T 恤。关注我们，看打脸现场。"

## 标签 3-5 个

`#闲鱼开箱` `#显微镜` `#家庭实验室` `#省钱攻略` `#理工男思维`

## 选题理由

**这条是"过程感"内容**——为 M2 的检测视频做铺垫。

- **破除"完美实验室"幻觉**：¥120 闲鱼设备 vs ¥350 全新的对比，**给"穷有穷做"的家庭实验室一个真实切口**
- **杨珂"专业度"露出**：光路系统、坏点、生产批次——这些是**QA 工程师的专业本能**，第一次让观众看到他的"硬核一面"
- **为检测视频引流**："下期测 T 恤"是天然的系列化钩子
- **不强科普**：杨珂讲参数的过程**可以剪快一点**，重点在"反差 + 人物"，不在知识点

> **风险提示**：闲鱼显微镜如果实际没到货，**可以先拍"杨珂在网上挑显微镜"的屏幕录制 + 曼曼吐槽**——内容核心不变。如果曼曼担心"被认出卖家/品牌纠纷"，把"Andonstar AD106S"换成"我们用的这款"即可，**不强调型号**。

# Script 4 — 实验过程型

> **主题**：先生做燃烧法检测，太太实时反应（震惊/嫌弃/惊喜）

## 标题候选

1. 我让老公用打火机烧我的 ¥499 真丝衬衫，3 秒后我哭了
2. 真丝、纯棉、仿真丝，一个打火机烧出来三个完全不同的结果
3. 服装设计师老婆看老公烧她衣服——每 1 秒一个表情包

> 公式拆解：动作+价格+反转+情绪（候选 1）+ 对比+悬念（候选 2）+ 节奏数字+情绪词（候选 3）

## 封面方向

**曼曼手捂嘴"震惊"脸 + 桌上三种面料残骸并排**。**视觉冲击直接给到观众**——让他们不点进来看就难受。

## 开头 3 秒钩子
