# 一、三平台分发策略总览

## 1.1 战略分工

> **总原则：一次拍摄 + 三个版本（不是三个完全独立的视频）**

| 平台 | 角色 | 精力占比 | 战略地位 | 核心指标 |
|------|------|---------|---------|---------|
| **小红书** | **主战场** | **60%** | 首发 + 沉淀 | 粉丝量、爆文数、搜索流量、蒲公英接单 |
| **抖音** | **副战场** | **25%** | 破圈 + 反种草爆款 | 完播率、爆款率、私域引流 |
| **B 站** | **长尾场** | **15%** | 深度内容 + 高粘性粉丝 | 涨粉率、收藏率、专栏关注 |

**为什么这么分**：
- **小红书 60%**：79% 女性 + 25-40 岁 + 72% 搜索后做决策 = **精准转化主场**
- **抖音 25%**：3.5 亿月活 + 算法推荐 = **破圈拉新**，但流量爆款后**用户不沉淀**（与小红书"沉淀"互补）
- **B 站 15%**：长视频友好 + 18-35 岁 + 知识向 = **深度人设沉淀**，涨粉慢但**粉丝粘性极高**（适合 M3+ 养粉 + 后期变现）

## 1.2 平台用户画像对比

| 维度 | 小红书 | 抖音 | B 站 |
|------|--------|------|------|
| **性别** | 79% 女性 | 男女比约 48:52 | 男女比约 57:43 |
| **年龄** | 25-40 岁 | 全年龄（25-35 主力）| 18-35 岁（22-30 主力）|
| **月活** | ~3 亿 | ~3.5 亿 | ~3.4 亿（DAU 约 1 亿）|
| **流量机制** | 50% 搜索 + 50% 推荐 | 90%+ 算法推荐 | 推荐 + 关注 + 搜索（搜索占比高）|
| **内容长度** | 1-3 分钟最优 | 15-60 秒 | 5-15 分钟 |
| **决策路径** | 搜索后做购买决策（72%）| 沉浸式刷流 | 收藏 + 关注后回看 |
| **最佳内容** | 穿搭 / 检测 / 面料科普 / 避坑 | 反种草 / 强钩子 / 强对比 | 深度拆解 / 行业科普 / 设计师视角 |
| **爆款规律** | 视频笔记占爆文 93% | 3 秒完播率决定流量 | 完播率 + 收藏率决定推荐 |

## 1.3 三个版本的关系

> **核心心法**：小红书是"完整版"（中规中矩 1-3 分钟），抖音是"切片版"（高潮前置 15-60 秒），B 站是"扩展版"（深度展开 5-15 分钟）

```
同一个拍摄日
   ↓
原始素材 30-60 分钟（曼曼正拍 + 副机位俯拍 + 杨珂声音 + 实验镜头 + 数据特写）
   ↓
├─→ 小红书版：完整版 1-3 分钟（剪辑最核心叙事）
├─→ 抖音版：切片版 15-60 秒（取最炸 1 个钩子 + 1 个反转）
└─→ B 站版：扩展版 5-15 分钟（完整叙事 + 数据可视化 + 行业延展 + 知识卡片）
```

**关键约束**：
- **3 个版本共享 80% 素材**（曼曼画面 + 实验镜头 + 杨珂声音）—— 拍摄日就一次
- **剪辑差异化 20%**（开头 3 秒 + 字幕风格 + 节奏）—— 剪辑日分先后做
- **数据 / 金句 100% 复用**—— 这是声音档的最大红利

## 1.4 首发顺序与发布时间差

| 顺序 | 平台 | 时间差 | 原因 |
|------|------|--------|------|
| **首发** | **小红书** | T+0 | 主战场，沉淀搜索流量 |
| **次发** | **抖音** | T+3 ~ T+7 天 | 验证过内容有效后改造，避免重复审核 |
| **最后发** | **B 站** | T+7 ~ T+14 天 | 深度版靠长尾，发布节奏不抢小红书热度 |

**为什么不反过来**：
- 抖音首发会让小红书显得"二手"
- B 站首发会让"小红书 + 抖音"显得仓促
- **小红书首发 = 主创主场 = 最有沉淀感**

## 3.2 剪辑工作流（3 个剪辑日）

> **严格按"小红书版先做 → 抖音版改 → B 站版扩"的顺序**

### 剪辑日 1：小红书版（T+1）

**目标**：完整版 1-3 分钟
**工具**：剪映
**耗时**：2-3 小时

**步骤**：
1. 导入原始素材（30 分钟）
2. 粗剪 1 遍（30 分钟）—— 按声音稿顺序剪
3. 精剪 + 调音（60 分钟）—— 杨珂声音单独成轨 + 字幕
4. 调色 + 字幕（30 分钟）
5. 导出 + 预览（15 分钟）

**关键约束**：
- 小红书 1:30-2:30 是最优长度
- 开头 3 秒决定流量，必须强钩子
- 杨珂声音 + 字幕必须清晰

### 剪辑日 2：抖音版（T+3 ~ T+5）

**目标**：切片版 30-60 秒
**工具**：剪映（可复用小红书版的工程）
**耗时**：1-1.5 小时

**步骤**：
1. 复制小红书版工程（10 分钟）
2. 删除非核心段落，保留最炸 1 个钩子 + 1 个反转（20 分钟）
3. 调整开头 3 秒（强钩子前置）（15 分钟）
4. 放大字幕 + 警示色 + BGM 切换（20 分钟）
5. 导出 + 预览（10 分钟）

**关键约束**：
- 抖音 30-45 秒是最优长度
- 开头 0.5 秒必须视觉冲击
- 字幕占屏 1/3 是抖音标配

### 剪辑日 3：B 站版（T+7 ~ T+10）

**目标**：扩展版 8-15 分钟
**工具**：剪映 / Pr（更专业）
**耗时**：4-6 小时

**步骤**：
1. 重新梳理素材（30 分钟）—— 找 B 站独有的深度镜头
2. 写章节结构（30 分钟）—— 5-7 个章节 + 进度条
3. 制作数据卡 / 表格（60 分钟）—— Canva / Figma
4. 粗剪 + 章节标记（90 分钟）
5. 精剪 + 调音 + 字幕（90 分钟）
6. 调色 + 封面设计（30 分钟）
7. 导出 + 预览（15 分钟）

**关键约束**：
- B 站 8-12 分钟是最优长度
- 章节进度条是 B 站长视频标配
- 数据可视化弥补"声音档"视觉弱
- 封面尺寸 1146×717（16:10）

| **5** | **数据可视化**（表格 / 对比 / 实验）| B 站弹幕文化 + 收藏率高 | "10 件童装 6 项检测完整数据表" |

**应避开**：
- ❌ 纯娱乐 / 搞笑（B 站不奖励）
- ❌ 强情绪喊麦（B 站偏冷静）
- ❌ 短于 3 分钟（B 站长视频生态）
- ❌ 没有章节 / 进度条（影响完播）
- ❌ 不严谨的"伪科学"（B 站观众会挑刺）

# 五、抖音启动策略

> **抖音的破冰逻辑和小红书不同**：算法推荐 = 任何内容都有爆款机会
> **声音档在抖音有独特优势**：用户对"画外音"接受度极高，金句更容易爆

## 5.1 抖音的破冰逻辑

### 与小红书的核心差异

| 维度 | 小红书 | 抖音 |
|------|--------|------|
| **流量机制** | 50% 搜索 + 50% 推荐 | 90%+ 算法推荐 |
| **爆款条件** | 关键词命中 + 互动 | 3 秒完播率 + 互动 |
| **起号难度** | 中（需 1k 粉才能带货）| **低**（不需要 1k 粉也能起号）|
| **变现门槛** | 蒲公英 1k 粉 | 橱窗 1k 粉 / 直播 0 粉 |
| **内容长度** | 1-3 分钟 | 15-60 秒 |
| **粉丝价值** | 高（精准 + 决策型）| 中（泛流量 + 围观）|
| **内容沉淀** | 强（搜索长尾）| 弱（爆款 3 天后衰减）|

### 抖音的"流量池"机制

```
发布视频
   ↓
初始流量池：200-500 播放
   ↓ 完播率 > 30% + 互动率高
二级流量池：1k-5k 播放
   ↓ 完播率 > 40% + 互动率更高
三级流量池：1w-10w 播放
   ↓ 持续高互动
爆款流量池：50w+ 播放
```

**关键指标**：
- **完播率**（最重要）：3 秒 + 整体完播
- **互动率**：点赞 / 评论 / 收藏 / 转发
- **关注转化率**：看到账号名后点关注的比例

## 5.2 30 天启动 5k 粉路径

> **目标**：30 天抖音粉丝从 0 → 5,000
> **路径**：1 周 1-2 条 + 每条冲爆款 + 主页导流到小红书

### 路径拆解

| 周次 | 内容计划 | 预期涨粉 | 关键动作 |
|------|---------|---------|---------|
| **W1** | 1 条（声音档破冰）| 100-500 | 账号装修 + 第 1 条试水 |
| **W2** | 1-2 条（强钩子切片）| 500-1,500 | 测爆款模型 |
| **W3** | 2 条（爆款改造 + 新选题）| 1,500-3,000 | 集中冲爆款 |
| **W4** | 2-3 条（爆款复制）| 3,000-5,000 | 主页导流 + 私信话术 |
| **累计** | **6-8 条** | **5,000+** | |

### 关键策略

#### 1. 第 1 条抖音应该发什么

> **推荐：声音档破冰型**（改编自 Phase 2 Script 1）

**理由**：
- 账号定位建立 + 声音档人设首次亮相
- "声音档" 在抖音是**强差异化**（抖音大部分是真人出镜）
- 3 秒完播率高（"他只肯出声音" 是天然钩子）

**剪辑要点**：
- **30-45 秒**（不要超过 60 秒）
- **开头 0.5 秒** = 曼曼正拍 + 文字弹出"他只肯出声音"
- **强 BGM** = 抖音热门 BGM（不要用小红书的轻钢琴）
- **字幕大** = 占屏 1/3
- **结尾导流** = "完整版在小红书，搜 XXX"

#### 2. 爆款复制模型

- **W2 第 1 条**：测"UV 灯下童装"切片（强钩子 + 反差视觉 + 妈妈痛点）
- **W2 第 2 条**：测"99 vs 999 白 T"切片（价格反差 + 显微特写）
- **W3-W4**：哪个模型爆了就复制 2-3 次（爆款 = 同模板 + 不同素材）

#### 3. 主页导流设计

- **抖音个人简介**："设计师妈妈 + QA 工程师老公 = 全网唯一有家庭实验室\n**完整版在小红书**：设计师妈妈的服装实验室"
- **背景图**：实验室台面 + 7 件设备 + "小红书同名"
- **置顶视频**：爆款 + 引导主页

## 5.3 抖音的"流量池"机制怎么利用

### 5.3.1 完播率提升技巧

| 技巧 | 应用方式 |
|------|---------|
| **0.5 秒强钩子** | 显微特写 / UV 灯亮起 / 反差瞬间 |
| **悬念前置** | "这件衣服居然——"（0.5 秒说半句）|
| **进度条** | 字幕显示"00:15 高潮" |
| **结尾反转** | 最后一秒给惊喜（"评论区告诉我你买过几个"）|
| **多机位快剪** | 每 2-3 秒切一个画面（防划走）|

### 5.3.2 互动率提升技巧

| 技巧 | 应用方式 |
|------|---------|
| **争议性话题** | "99 的白 T 你敢穿吗？" |
| **投票式提问** | "评论区打 1 = 会买 / 2 = 不会" |
| **置顶评论引导** | "主页有完整版，评论区扣 1 我私发" |
| **回复评论** | 每条爆款评论都回复（带动互动）|
| **评论区彩蛋** | "前 10 个评论的姐妹送样品"（慎用，可能违规）|

### 5.3.3 发布时间（抖音最优）

- **早 7:00-9:00**（起床刷流）
- **午 12:00-14:00**（午休刷流）
- **晚 19:00-22:00**（黄金时段）
- **周末延后 1 小时**（周末用户晚起）

**最优**：工作日 19:30 / 周末 20:30

## 5.4 声音档在抖音的优势

> ⚠️ **声音档在抖音是"红利平台"**——用户对画外音接受度极高

### 5 大优势

1. **画外音更易制造"反差记忆点"**：
   - "我老公是 QA 工程师，他看这件衣服说'克重 180g'——" 这种**理工男对营销话术的反应**是抖音天然爆款
2. **金句密度高**：
   - 抖音短切片天然适合"1 句金句 + 1 个画面"的组合
   - 声音档的金句**比脸更易传播**（听到就能记）
3. **解放曼曼镜头**：
   - 曼曼可以更精致地构图（不再受"夫妻同框"绑定）
   - 画面可以更"实验室"调性（更适合抖音的"专业感"标签）
4. **后期灵活**：
   - BGM 切换 / 变声 / 音效 / 字幕动画 —— 都不影响声音档的画面
   - **抖音的"二次创作"生态对声音档友好**
5. **夫妻档"人设"更聚焦**：
   - 抖音用户喜欢"明确分工"的夫妻档
   - "设计师老婆 + 工程师老公"的对比，比"夫妻同框"更易传播

### 抖音专属金句模板

> **杨珂画外音 + 1 个画面 = 抖音爆款切片**

| 选题 | 杨珂金句 | 画面 |
|------|---------|------|
| UV 灯下 | "这工艺不稳定，是增白剂过量" | UV 灯下衣服亮起 |
| 显微特写 | "克重 180g，织法单面平纹—— 容易变形" | 显微特写 |
| 燃烧法 | "这是化纤。真丝不会这样烧" | 燃烧实验 |
| 甲醛检测 | "0.08mg/m³，超标 0.01。新房都不敢这么搞" | 试剂变色 |
| 反种草 | "奢侈品定价里 70% 是品牌溢价" | 价格表 |

> **B 站的耐心是值得的**：涨粉慢但粉丝粘性极高
> **B 站是"沉淀型"平台**：不要急着变现，先涨粉 + 立专业人设

## 6.1 B 站的破冰逻辑

| **爆款条件** | 关键词 + 互动 | 3 秒完播 | 完播 + 收藏 + 弹幕 |
| **内容长度** | 1-3 分钟 | 15-60 秒 | 5-15 分钟 |
| **粉丝粘性** | 中 | 低 | **极高**（收藏率 + 关注率高）|

- **收藏率决定推荐**：B 站算法看"收藏 + 不完播 = 垃圾"，所以**完播 + 收藏**是核心
- **弹幕文化**：B 站用户喜欢"边看边吐槽"，弹幕是粘性指标
- **三连文化**：点赞 + 投币 + 收藏 = 用户的"信仰充值"

## 6.4 声音档在 B 站的局限与应对

> ⚠️ **B 站是视觉深度平台，"只有声音"对长视频不利**
> **必须给 B 站加"曼曼讲解 + 数据可视化"补足视觉**

### 5 大局限

1. **B 站是视觉深度平台**：
   - 长视频需要持续视觉刺激，光听声音容易走神
   - 声音档的"曼曼画面 + 声音"如果**画面变化少**，B 站完播率会低
2. **弹幕文化**：
   - B 站用户喜欢"边看边吐槽"，声音档"看不到表情"会让弹幕参与感弱
3. **专业感需要视觉支撑**：
   - 数据 / 表格 / 对比图在 B 站是标配，纯声音讲解专业感不足
4. **节奏偏慢**：
   - B 站长视频节奏本来就慢 + 声音档节奏更慢 = 双慢 = 危险
5. **缺乏"高能瞬间"**：
   - B 站用户喜欢"名场面"（数据对比、实验反转、设计师金句），声音档如果画面单调会缺名场面

### 8 个应对策略

#### 1. **数据可视化卡片**（最重要）

- **使用工具**：Canva / Figma / 剪映
- **插入位置**：每个章节开头 + 关键数据节点
- **必备元素**：对比表格 / 数据条 / 圆形比例图 / 关键词云
- **示例**：
  - 99 vs 999 白 T："克重 180 vs 220 / 纱支 32 vs 50 / 织法 单面 vs 双面"
  - 10 件 UV 灯："3 件 / 30% 荧光反应 / 1 件 / 10% 严重超标"

#### 2. **多机位快剪**（弥补画面单调）

- **机位 1**：曼曼正拍（半身 / 全身）
- **机位 2**：桌面俯拍（实验 / 数据 / 设备）
- **机位 3**：显微特写（200 倍 / 500 倍）
- **机位 4**：设备特写（UV 灯 / 照布镜 / 试剂）
- **机位 5**：屏幕录制（闲鱼 / 检测数据 / 标准查询）

**剪辑节奏**：每 30-60 秒切一次机位（保持视觉新鲜感）

#### 3. **章节进度条**（B 站标配）

- **5-7 个章节**，每个章节 1-2 分钟
- **章节标题明确**："显微特写""数据解读""设计师视角"等
- **章节之间用过渡音**（轻音效）

#### 4. **专业术语字幕标黄**（增强"专业感"）

- **克重 / 纱支 / 织法 / 取向度 / 抗起球** 等专业术语
- **黄色字体** + 简单解释（在屏幕一角）
- **不要让用户"听不懂就划走"**

#### 5. **关键帧"名场面"标记**（让弹幕有话题）

- **金句字幕放大**（如"克重 180g" 占屏 1/4）
- **关键数据定格 1-2 秒**（让用户有时间消化）
- **"曼曼震惊脸" + "杨珂金句"** 交叉剪辑

#### 6. **曼曼的"个人魅力"补足**（声音档视觉弱项）

- **表情特写**（震惊 / 思考 / 笑 / 严肃）
- **手部动作**（指着屏幕 / 操作设备 / 翻面料）
- **服装穿搭**（每期穿不同的实验室风服装）
- **环境细节**（实验室灯光 / 7 件设备 / 女儿的衣服 / 笔记本）

#### 7. **杨珂画外音 + 字幕强化**（声音档核心价值保留）

- **杨珂声音单独成轨**
- **关键术语字幕同步弹出**
- **"金句"用动画字幕**（打字机效果 / 放大效果）

#### 8. **结尾"双金句"**（B 站长视频收尾仪式）

- **曼曼金句**："不是为了上镜，是为了她"
- **杨珂金句**："数据不会骗人"
- **双金句交叉剪辑 + 字幕放大**

### B 站"声音档专属"剪辑清单

> **声音档视频发 B 站时，必须做以下 3 件事**：

1. **加数据卡**（每章节 1-2 个，总计 5-10 个）
2. **加章节进度条**（5-7 个章节 + 进度条）
3. **加专业术语字幕**（标黄 + 解释）

**这 3 件事是"声音档"在 B 站活下去的底线**。

# 七、⏰ 时间分配表（每周 30-35 小时）

# 九、⚠️ 声音档特殊提示

> **三平台对"画外音"的态度差异巨大，必须针对性应对**

## 9.1 三平台对"画外音"的态度对比

| 平台 | 对画外音的接受度 | 原因 | 声音档策略 |
|------|----------------|------|----------|
| **小红书** | ⭐⭐⭐⭐ **高** | 女性向 + 慢节奏 + 故事感强 | **声音档主战场**——画外音 + 故事 + 金句是核心 |
| **抖音** | ⭐⭐⭐⭐⭐ **极高** | 算法推荐 + 短切片 + 金句传播 | **声音档红利平台**——金句 + 反差 = 爆款 |
| **B 站** | ⭐⭐ **低** | 视觉深度 + 长视频 + 弹幕文化 | **声音档弱场**——必须加视觉补足（数据卡 / 多机位）|

## 9.2 三平台声音档特殊处理清单

### 小红书（声音档主战场）

- **声音占比 50-70%**：曼曼 + 杨珂快问快答
- **杨珂画外音 + 字幕强化**：字幕标黄 + 关键术语解释
- **金句密度高**：每 30 秒 1 个金句
- **慢节奏**：1-3 分钟完整叙事

### 抖音（声音档红利平台）

- **杨珂 1 句金句 = 爆款钩子**：例"克重 180g""这工艺不稳定""70% 是品牌溢价"
- **声音占比 30-50%**：以画面为主 + 杨珂金句点缀
- **节奏快**：30-45 秒切片
- **大字幕**：杨珂的话必须大字幕

### B 站（声音档弱场）

- **必须加视觉补足**：数据卡 + 多机位 + 章节进度条
- **杨珂画外音 + 字幕强化**：专业术语标黄 + 简单解释
- **节奏中等**：8-15 分钟，但每 30-60 秒切一次机位
- **关键帧"名场面"**：金句字幕放大 + 关键数据定格

## 9.3 声音档三平台常见问题

### Q1：杨珂的声音在哪个平台最强？

> **抖音 > 小红书 > B 站**
> - **抖音**：金句传播 + 算法推荐 = 声音档红利
> - **小红书**：女性向 + 慢节奏 = 声音档稳场
> - **B 站**：长视频 + 视觉深度 = 声音档弱场

### Q2：杨珂的声音在哪个平台最弱？

> **B 站长视频**——长视频只有声音会让用户走神
> **应对**：加数据卡 + 多机位快剪 + 章节进度条 + 专业术语字幕

### Q3：抖音用户会不会觉得"画外音很奇怪"？

> **不会**——抖音有大量"画外音 + 字幕"的爆款（情感 / 美食 / 知识类）
> **关键**：杨珂的声音要"自然 + 真实 + 工程师调性"，**不要表演**

### Q4：B 站用户会不会吐槽"看不到老公"？

> **会**——B 站弹幕会问"为什么不露面"
> **应对**：
> - 评论区引导："先听完他这次的深度回答"
> - 视频里加一句："他就在镜头外操作设备"
> - **B 站长视频 + 多机位** = 让"看不到脸"变成"专注内容"

### Q5：小红书用户会不会"想看老公"？

> **会**——小红书评论区会刷"想看老公"
> **应对**（参考 Phase 2 声音档规范）：
> - 话术引导："先听完他下次的专业回答"
> - 偶尔露"手部 + 设备操作"（不露脸）
> - 制造"延迟满足"：每周给一点点（比如露手）

## 9.4 声音档长期策略

### 短期（M1-M3）

- **3 平台都用声音档**（杨珂只出声音）
- **专注金句密度**（每条 3-5 个金句）
- **评论区引导**（"想看老公吗？先听完他这次的回答"）

### 中期（M3-M6）

- **小红书**：声音档稳定 + 偶尔露手
- **抖音**：声音档红利最大化 + 金句传播
- **B 站**：声音档 + 视觉补足（数据卡 + 多机位）

### 长期（M6+）

- **考虑杨珂"手部 + 设备"出镜**（不露脸）：增加视觉记忆点
- **考虑"声音档系列化"**（"杨珂金句集"）：B 站 / 抖音可做
- **考虑"杨珂个人专栏"**（B 站）：长视频深度讲解

## 9.5 声音档红线与禁忌

> 来自 Phase 2 声音档规范（**v2.0 必须遵守**）

1. **杨珂不能露脸**：连手部 + 设备操作时也要注意，**不能露出衣袖 / 手腕的皮肤明显特征**
2. **杨珂声音不能修太多**：原声最好，**最多降噪 + 调音量**，不要变声
3. **不要刻意"演"夫妻**：NG 痕迹保留、停顿保留、口误保留
4. **不要过度商业化声音档**：声音档的核心是"真实感"——金句密度可以高，但**不能像广告**
5. **不要让杨珂的工程师思维太强势**：他是辅助，**曼曼是主创**——所有结论以"曼曼觉得"为准
6. **三平台声音档调性统一**：杨珂声音 + 曼曼画面 = 跨平台一致性，**不要"小红书真实、抖音表演"**
