## 📋 使用说明

**这份选题库是干什么的？**

焦虑型选题 = 用户在搜索"如何不焦虑"时找到你。**不是制造焦虑，是精准匹配用户已有的焦虑。**

**为什么必须做焦虑型选题？**

1. **搜索流量占小红书大盘 50%**——焦虑型关键词（"甲醛""白T推荐""二孩妈妈穿搭"）的搜索量，是"分享日常"型内容的 5-10 倍
2. **焦虑型内容天然有收藏价值**——用户会收藏"以后买衣服前回来看"，CES 算法权重 ×1，是长尾流量来源
3. **焦虑型内容天然激发评论**——"我之前买过""我家孩子就这样"，评论区自带 UGC，CES 权重 ×4
4. **焦虑型内容与本账号定位 100% 匹配**——设计师妈妈 + 质量工程师爸爸 = 唯一能"治焦虑"的人设

**如何使用本文件？**

| 场景 | 怎么用 |
|------|--------|
| 周复盘选下条选题 | 翻"🎯 高价值选题 TOP 8"，按顺序挑 |
| 不知道挂哪个栏目 | 看"栏目归属"列；检测内容必带显微镜/UV/甲醛等设备 |
| 不知道用什么关键词写标题 | 抄"关键词"列到标题里（前 30 字内） |
| 不知道能不能做 | 翻末尾"⚠️ 选题红线"——黑名单不碰 |
| 排发布顺序 | 看"内容日历分布建议"和"M1 优先发"标注 |

**搜索热度判断依据**：
- **高**：小红书搜索框提示词 / 巨量算数月搜索量 > 5 万 / 竞品笔记数 1000+
- **中**：搜索量 1-5 万 / 竞品笔记 200-1000 / 长尾词
- **低**：搜索量 < 1 万 / 高度专业 / 几乎无竞品

**预估爆款指数说明**：
- ⭐⭐⭐⭐⭐ 必有爆款潜质（≥ 1 万赞的概率）
- ⭐⭐⭐⭐ 有爆款潜质，需要执行到位
- ⭐⭐⭐ 中等爆款
- ⭐⭐ 小爆款或长尾
- ⭐ 不确定，看运气

## 六、⚠️ 选题红线

> **以下焦虑型选题**虽然搜索量大、爆款概率高，但**会引发法律风险 / 道德争议 / 不可控后果**，**坚决不做**。

### 🚫 红线 1：点名品牌"黑名单"（法律风险）

| 不做的内容 | 原因 |
|----------|------|
| ❌ "XX 品牌甲醛超标，千万别买" | **没有国家检测报告 = 诽谤风险**。哪怕是真事，没报告就可能被起诉。 |
| ❌ "X 牌童装荧光剂严重超标" | 同上，**没有 CMA 认证报告 = 不可公开点名**。 |
| ❌ "某网红品牌是骗子" | 主观评价+无报告 = 名誉侵权。 |
| ❌ "X 品牌吃了会死人" | 严重公共安全风险，必须有官方报告。 |

**✅ 正确做法**：
- 有 CMA/SGS 报告的品牌检测 → 可以发，但要写"基于 XX 报告"
- 没有报告的品牌检测 → **用编号/盲测**（"5 号样品""样品 A"），不下品牌结论
- 总结类内容 → 写"哪些品牌历史上出过问题"（基于公开新闻），不写"现在这家有问题"

### 🚫 红线 2：制造恐慌型（道德风险）

| 不做的内容 | 原因 |
|----------|------|
| ❌ "你给孩子穿的衣服都是毒衣服" | 制造恐慌，违反账号"不制造焦虑"原则。 |
| ❌ "99% 的童装都不合格" | 没有数据支撑+制造恐慌=反噬账号信任。 |
| ❌ "穿了 X 年这种衣服会得癌症" | 严重健康误导，专业机构可能投诉。 |
| ❌ "所有便宜的衣服都不能买" | 价值判断过于绝对，违反账号"客观测评"调性。 |

**✅ 正确做法**：
- 用"实测+分级"代替"全盘否定"（"这 5 件里 2 件需注意"）
- 用"如何避免"代替"你已经被毒害"（"新衣服这样处理更安全"）
- 用"我的检测结果"代替"普遍真相"（"我家的样品测试结果"）

### 🚫 红线 3：未经验证的"科学结论"（专业风险）

| 不做的内容 | 原因 |
|----------|------|
| ❌ "这种面料会导致过敏" | 没有临床数据支持，专业医生可能反驳。 |
| ❌ "穿这个衣服会得白血病" | 严重健康误导，可能被举报封号。 |
| ❌ "X 物质致癌" | 涉及公共健康言论，需专业资质。 |
| ❌ "甲醛超标的衣服穿了 X 年后会怎样" | 毒理学结论需专业背书。 |

**✅ 正确做法**：
- 用"检测结果显示..."代替"会导致..."
- 引用权威来源（GB 国标 / SGS / 童装安全标准）
- 涉及健康话题，**写"建议咨询医生"**而不是下结论

### 🚫 红线 4：攀比/性别对立型（社区风险）

| 不做的内容 | 原因 |
|----------|------|
| ❌ "全职妈妈就是没价值" | 价值观导向错误，账号会被骂。 |
| ❌ "不会买衣服的女人不配当妈" | 制造对立，违反账号"治愈焦虑"调性。 |
| ❌ "老公不给你买包就是不爱你" | 性别对立，平台不推荐。 |
| ❌ "精致妈妈 vs 黄脸婆" | 制造焦虑+歧视，账号会被举报。 |

**✅ 正确做法**：
- 用"我作为妈妈的选择"代替"妈妈应该..."
- 用"找到适合自己的方式"代替"你应该 X"
- 涉及家庭关系，**展示"我和我先生"**而不是"男人/女人应该"

### 🚫 红线 5：孩子隐私+未授权（合规风险）

| 不做的内容 | 原因 |
|----------|------|
| ❌ 孩子正脸高清照 | 平台规则+孩子隐私。 |
| ❌ 孩子哭/受伤/情绪失控画面 | 违反未成年人保护。 |
| ❌ 未经同意拍摄其他孩子 | 肖像权+隐私。 |
| ❌ 暴露孩子学校/住址/姓名 | 安全风险。 |

**✅ 正确做法**（已写入计划书 4.5）：
- 女儿（4 岁）：背影/侧脸/低头/遮挡
- 儿子（8 岁）：征得同意后出镜，不露正脸
- 原则：穿搭是主线，颜值是加分项

### 🚫 红线 6：奢侈品真伪鉴定（专业风险）

| 不做的内容 | 原因 |
|----------|------|
| ❌ "这个 X 牌包是假的" | 涉及真伪鉴定，需官方授权，否则侵权。 |
| ❌ "X 品牌的 X 系列是 A 货做的" | 没有专业资质=诽谤风险。 |
| ❌ "教你用 X 招辨别 LV 真假" | LV 打过多次此类内容官司。 |

**✅ 正确做法**：
- 只说"我自己买过/卖过/了解过"，不说"这是假的"
- 涉及真伪 → "送中检/中奢"等专业机构
- 避免"教大家鉴别"，做"我的消费观察"
