# Winner HTML Projects

公开预览仓库，只放 Max 的两个 HTML/Web 项目的静态展示内容。

## 在线项目

- `math-adventure`：儿童数学冒险学习游戏，纯前端项目。
- `xiaohongshu-tools`：小红书内容生产工作台静态预览版。完整 AI/TTS/后端能力需要单独部署 Node 服务。

## 安全原则

本仓库不包含：

- Winner 长期记忆
- 家庭/健康/个人隐私
- `.env`
- API Key / Token / Cookie
- `node_modules/`
